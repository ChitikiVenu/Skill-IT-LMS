# Skill IT AI LMS

AI-powered technical learning platform for Skill IT Education.

## Learning tracks

- Cyber Security
- SOC
- AI & Machine Learning
- Data Science

## Student experience

- Dashboard
- My Courses
- Learning Path
- Video lessons and study materials
- Practical labs
- Quizzes and assessments
- Assignments and projects
- Certificates
- Attendance
- Skill Score
- AI Tutor and learning assistant
- Personalized learning recommendations

## Planned platform architecture

- Next.js + TypeScript
- PostgreSQL + Prisma
- NextAuth/Auth.js
- OpenAI-powered AI learning layer
- Vercel deployment
- Separate compute/lab infrastructure for technical environments

## Development stages

1. Student-first interface and navigation
2. Database and authentication
3. Courses, lessons, progress and assessments
4. AI tutor, assessment and personalized learning
5. Cyber/SOC/AI/Data Science labs
6. Certificates, skill scoring and career intelligence
7. Production hardening and deployment
